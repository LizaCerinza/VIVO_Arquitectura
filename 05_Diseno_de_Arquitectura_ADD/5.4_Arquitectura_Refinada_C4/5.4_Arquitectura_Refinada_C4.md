# 5.4 Arquitectura refinada · Modelo C4

El modelo C4 está escrito como código en **Structurizr DSL**, en el archivo [`workspace.dsl`](workspace.dsl). Un solo modelo genera todas las vistas, así que los elementos y las relaciones son los mismos en cada nivel.

| Nivel | Vista | Documento | Estado |
|---|---|---|---|
| 1 | Contexto del sistema (`C1_Contexto`) | [C1_Contexto.md](C1_Contexto.md) | Listo |
| 2 | Contenedores (`C2_Contenedores`) | [C2_Contenedores.md](C2_Contenedores.md) | Listo |
| 3 | Componentes de la API | [C3_Componentes_API.md](C3_Componentes_API.md) | Pendiente |
| 3 | Componentes del Procesador RNDC | [C3_Componentes_Procesador_RNDC.md](C3_Componentes_Procesador_RNDC.md) | Pendiente |

## Cómo ver los diagramas

**Opción 1: Structurizr Lite (local, con Docker).** Desde esta carpeta:

```bash
docker run -it --rm -p 8080:8080 -v "$(pwd)":/usr/local/structurizr structurizr/lite
```

Luego abrir `http://localhost:8080`.

**Opción 2: editor en línea.** Copiar el contenido de `workspace.dsl` en el playground de Structurizr (`https://playground.structurizr.com`) y elegir la vista `C1_Contexto` o `C2_Contenedores`.

**Opción 3: VS Code.** La extensión *Structurizr* resalta la sintaxis del DSL. Para ver los diagramas se usa la opción 1 o la 2.

## Trazabilidad con los drivers

| Contenedor | Drivers que atiende | Tácticas y patrones del Punto 4 |
|---|---|---|
| API Gateway | D-03 | Security Gateway, Intercepting Validator, validar entrada |
| API de Recepción y Gestión | D-01, D-02, D-03, D-05 | Degradación controlada, receptor idempotente, outbox, máquina de estados, autorización por operación, auditoría, repuesto redundante |
| Procesador RNDC | D-01, D-02, D-04 | Circuit Breaker, timeouts, reintento, throttling, adaptador RNDC, conciliador (Scheduler Agent Supervisor) |
| Base de Datos Transaccional | D-02, D-03, D-05 | Transacciones, bitácora inmutable, separación por empresa, cifrado |
| Cola Durable | D-01, D-02 | Cola de nivelación de carga, consumidor idempotente |
| Monitor y Alertas | D-01 | Monitoreo de condiciones, ping/eco, informar a los actores |
| Consola de Administración | D-05 | Revisión manual, consulta de la auditoría |
