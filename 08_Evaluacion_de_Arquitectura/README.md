# 8. Evaluación de Arquitectura

> **Lo que pide la tarea:** presentación de máximo 20 minutos ante el comité evaluador con:
> - Contexto del problema: requerimientos y usuarios
> - Drivers de arquitectura: metas del negocio, atributos de calidad, escenarios de QA, restricciones y preocupaciones arquitectónicas
> - Diseño de arquitectura: modelo C4 hasta el nivel de componentes
> - Registro de decisiones de arquitectura (ADR)
> - Análisis de riesgo
